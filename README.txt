PRAJWAL JAGTAP — PORTFOLIO WEBSITE
==================================
Files:
- index.html: website content
- styles.css: responsive styling and layout
- script.js: mobile menu, scroll progress, current year and copy-email interaction

RUN LOCALLY
1. Extract the ZIP.
2. Keep all three files in the same folder.
3. Open index.html in Chrome or another browser.

BEFORE SUBMISSION
1. Edit index.html in VS Code or Notepad.
2. Your email and GitHub profile have already been added. Verify the email is the one you want public.
3. Your GitHub profile link is set to https://github.com/jprajwal282002. Add your LinkedIn profile URL if applicable.
4. Review project descriptions and ensure they accurately represent what you implemented.
5. Test the website on desktop and mobile.

PUBLISH WITH GITHUB PAGES
1. Create a public GitHub repository, e.g. prajwal-portfolio.
2. Upload index.html, styles.css and script.js to the repository root.
3. Go to Settings > Pages.
4. Choose Deploy from a branch, select main and /(root), then Save.
5. Open the public URL shown by GitHub Pages after deployment.

This is a static website; no backend or package installation is required. The email link opens the visitor's email application and is not a backend contact form.
